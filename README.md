# 梦中飞行

根据一个反复出现的梦做成的 3D 网页游戏：
被僵尸和鬼追 → 跳进湖里游泳 → 游着游着，用游泳的姿势飞起来 →
越飞越高 → 飞越高楼 → 落在树尖上，在树与树之间跳跃。

## 怎么玩

第一次（从 GitHub 克隆后）先安装依赖（需要 Node.js）：

```bash
npm install
```

然后双击 `启动游戏.bat`（需要电脑装有 Python），浏览器会自动打开游戏。

也可以手动启动：在本目录运行 `python -m http.server 8283`，
然后浏览器打开 http://localhost:8283 。

## 操作

| 按键 | 作用 |
|------|------|
| W A S D / 方向键 | 移动 / 转向 |
| 空格 | 跳跃；空中 = 划水冲刺（飞行的关键，一下一下按）|
| Shift | 飞行时下降 |
| S | 飞行时减速 |
| 回车 | 开始 / 继续 |

## 梦境流程

1. **逃亡** —— 墓地里僵尸和鬼在追你，跑向前方发光的湖（被抓到会重新开始）
2. **游泳** —— 僵尸不敢下水。往前游，积攒"梦力"
3. **起飞** —— 梦力攒满就飞起来了！保持蛙泳姿势，按空格划水，越飞越高
4. **爬楼** —— 飞越城市，落在最高的摩天楼楼顶
5. **树尖** —— 森林里的杉树尖可以站立；树尖起跳会跳得特别高，连跳 5 棵树，天就亮了
6. **梦醒之后** —— 还可以继续自由飞行

## 技术

- Three.js（本地 node_modules，无需联网）
- 纯前端，单页面，无构建步骤
- `game.js` 末尾有 `window.__dream` 调试钩子（自动化测试用）
