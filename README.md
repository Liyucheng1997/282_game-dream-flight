# 梦中飞行

根据一个反复出现的梦做成的 3D 网页游戏：
被僵尸和鬼追 → 跳进湖里游泳 → 游着游着，用游泳的姿势飞起来 →
越飞越高 → 飞越高楼 → 落在树尖上，在树与树之间跳跃 → 天亮了。

## 怎么玩

第一次（从 GitHub 克隆后）先安装依赖（需要 Node.js）：

```bash
npm install
```

然后双击 `启动游戏.bat`（需要电脑装有 Python），浏览器会自动打开游戏。

也可以手动启动：在本目录运行 `python -m http.server 8283`，
然后浏览器打开 http://localhost:8283 。

## 操作

| 按键 | 作用 |
|------|------|
| W A S D / 方向键 | 移动 / 转向 |
| 空格 | 跳跃；空中 = 蛙泳划水（飞行的关键，一下一下按）|
| Shift | 飞行时下降 |
| S | 飞行时减速 |
| M | 静音 |
| 回车 | 开始 / 继续 |

## 梦境流程

1. **逃亡** —— 月夜的墓地里，坟一座座裂开，僵尸爬出来，鬼从陵墓里飘出来。沿着土路跑向发光的湖（被抓到会重新开始）
2. **游泳** —— 僵尸和鬼不敢下水，聚在岸边伸着手。蛙泳往前游，积攒“梦力”，湖面荡开会发光的涟漪
3. **起飞** —— 梦力攒满就飞起来了！保持蛙泳的姿势，按空格划水，每划一下身后的空气都像水一样荡开
4. **越飞越高** —— 飞过亮着窗灯的城市，穿过云层，飞到云海之上
5. **爬楼** —— 落在最高那栋摩天楼楼顶的停机坪上
6. **树尖** —— 森林里有几十棵比楼还高的巨杉，树尖在月光下发亮，可以站在上面张开双臂保持平衡；树尖起跳会跳得特别高，梦里跳树总能刚好落上。连跳 5 棵树，天就亮了
7. **梦醒之后** —— 还可以在日出里继续自由飞行

天色会随着梦的进度，从深夜慢慢变成黎明。

## 技术

- Three.js 0.160（本地 node_modules，无需联网；标题字体来自 Google Fonts，离线时自动退回系统字体）
- 纯前端，无构建步骤，ES 模块 + importmap
- 所有模型、贴图、音效都是代码生成的，没有任何外部素材

| 文件 | 内容 |
|------|------|
| `src/main.js` | 游戏状态、物理、敌人 AI、相机、HUD |
| `src/sky.js` | 天空着色器（月亮、星空、银河、高空云）和夜→晨的大气颜色 |
| `src/terrain.js` | 地形高度函数（渲染和碰撞共用）、草、湖边的芦苇 / 发光的花 / 睡莲 |
| `src/water.js` | 带倒影和涟漪的湖面 |
| `src/graveyard.js` | 墓碑、陵墓、铁栅栏、枯树、灯笼与蜡烛 |
| `src/city.js` | 楼群、窗灯、楼顶杂物、航标灯、道路和车灯 |
| `src/forest.js` | 巨杉与林海（会随风摇摆） |
| `src/characters.js` | 有关节的人形骨架、各种动作姿势（跑、蛙泳、滑翔、平衡……）、僵尸、幽灵 |
| `src/fx.js` | 云海、地面雾、光尘、萤火虫、粒子、空中涟漪、指引光柱 |
| `src/post.js` | 辉光与梦境滤镜 |
| `src/audio.js` | 合成的氛围音乐、风声、心跳、水花 |

`src/main.js` 末尾有 `window.__dream` 调试钩子（自动化测试用），例如 `__dream.jump('tree')` 直接跳到树尖阶段。
